# CIFAR-10 CNN Image Classifier

## Project Overview

This project focuses on building and evaluating Convolutional Neural Networks (CNNs) for image classification using the CIFAR-10 dataset.

The project is implemented using Python, TensorFlow, and Keras. It explores CNN fundamentals, different architectures, data augmentation techniques, and transfer learning to understand how deep learning models identify and classify images.

## Dataset

The project uses the CIFAR-10 dataset, which contains 60,000 colour images divided into 10 different classes.

- Training Images: 50,000
- Testing Images: 10,000
- Image Dimensions: 32 × 32 pixels
- Colour Channels: RGB
- Number of Classes: 10

### Classes

1. Airplane
2. Automobile
3. Bird
4. Cat
5. Deer
6. Dog
7. Frog
8. Horse
9. Ship
10. Truck

## Project Implementation

### 1. Data Loading and Preprocessing
- Loaded the CIFAR-10 dataset.
- Explored image shapes, labels, and data types.
- Visualised sample images from all 10 classes.
- Normalised pixel values between 0 and 1.
- Applied one-hot encoding to class labels.

### 2. Convolution Operations
- Implemented manual convolution using an edge detection kernel.
- Studied VALID and SAME padding.
- Compared different stride values.
- Visualised feature maps generated by convolutional layers.

### 3. CNN Architecture
- Explored MaxPooling and AveragePooling.
- Studied Flatten layers.
- Implemented the LeNet-5 architecture.
- Built a custom CNN architecture for CIFAR-10 classification.

### 4. Model Training and Evaluation
- Studied forward propagation and backpropagation in CNNs.
- Trained CNN models using the Adam optimiser.
- Implemented EarlyStopping and ReduceLROnPlateau callbacks.
- Analysed training and validation accuracy and loss.
- Evaluated model performance using test accuracy and a confusion matrix.
- Visualised misclassified images.

### 5. Data Augmentation
- Applied image transformations using ImageDataGenerator.
- Implemented augmentation using Keras preprocessing layers.
- Compared model performance with and without augmentation.

### 6. Transfer Learning
- Implemented MobileNetV2 for feature extraction.
- Used pre-trained ImageNet weights.
- Performed fine-tuning by unfreezing selected layers.
- Compared different model architectures and their performance.

### 7. Residual Connections
- Implemented a residual connection block using the Keras Functional API.
- Explored skip connections and their role in deep neural networks.

## Model Comparison

The project compares the following six approaches:

1. LeNet-5
2. CNN from Scratch
3. CNN with ImageDataGenerator Augmentation
4. CNN with Keras Augmentation Layers
5. MobileNetV2 – Feature Extraction
6. MobileNetV2 – Fine-Tuning

The models are compared based on test accuracy and parameter count.

## Installation

Clone the repository:

```bash

```

Navigate to the project directory:

```bash
cd CIFAR10-CNN-Image-Classifier
```
